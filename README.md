# virtual-quick-note
# 📝 QuickNote Pro

QuickNote Pro is a modern full-stack note-taking web application built using HTML, CSS, JavaScript, Python Flask, and SQLite.
The application allows users to create, edit, delete, search, and manage notes dynamically with a clean and responsive user interface.

This project demonstrates frontend-backend integration, REST API communication, database connectivity, and CRUD operations in a simple yet professional way.

---

# 🚀 Features

* ✅ Create Notes
* ✅ Edit Existing Notes
* ✅ Delete Notes
* ✅ Search Notes Instantly
* ✅ Dark Mode Toggle
* ✅ Responsive Modern UI
* ✅ Animated Note Cards
* ✅ Timestamp for Notes
* ✅ SQLite Database Storage
* ✅ Flask REST API Backend

# 📌 API Endpoints

| Method | Endpoint       | Description     |
| ------ | -------------- | --------------- |
| POST   | `/add`         | Add new note    |
| GET    | `/notes`       | Fetch all notes |
| PUT    | `/update/<id>` | Update note     |
| DELETE | `/delete/<id>` | Delete note     |
